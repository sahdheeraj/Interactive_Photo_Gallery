# 📸 Interactive Photo Gallery

A simple and responsive **photo gallery web application** that fetches high-quality images from the **Unsplash API**.  
Users can search for any keyword (e.g., nature, cars, travel) and explore beautiful images in a grid layout.

## Features
- 🔍 Search images by keyword  
- 🖼️ Fetches real-time photos from Unsplash API  
- 📱 Responsive grid layout for different screen sizes  
- ✨ Hover effects on images  
- 🔗 Click an image to view in full size (Unsplash link)  

## Tech Stack
- **HTML5**  
- **CSS3**  
- **JavaScript (Fetch API)**  
- **Unsplash API**
